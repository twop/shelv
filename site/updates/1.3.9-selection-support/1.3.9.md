# Version 1.3.9 - Selection Argument Support

This release adds powerful new capabilities for working with selected text in custom commands.

## What's New

### Selection Argument Support

JavaScript functions in `InsertText` commands can now receive selected text as an argument, enabling powerful text transformation workflows:

- Use `selection` child node in KDL configuration to pass selected text to JS functions
- Enables custom text transformation commands (e.g., wrap in quotes, make uppercase, format code)
- Updated system prompt and README with examples and documentation

### Example Usage

Here's how you can create a command that wraps selected text in quotes:

```kdl
command "wrap-in-quotes" {
  insert-text {
    js-code r#"(selection) => `"${selection}"`"#
    selection
  }
}
```

Or convert text to uppercase:

```kdl
command "uppercase" {
  insert-text {
    js-code "(selection) => selection.toUpperCase()"
    selection
  }
}
```
